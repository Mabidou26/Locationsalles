# Locationsalles
Description de salles pour professionnel et particuliers
📍 Locationsalles — Location d'espaces événementiels "Loc events" 📝 Description

Plateforme de localisation de salles destinées aux professionnels et aux particuliers pour l'organisation d'événements (réunions, fêtes, conférences, etc.).

⚙️ Prérequis

PHP / Compositeur

Symphonie

Faire

Base de données configurée
